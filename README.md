# Last Words of a Doomed Agent

Entry for the make.fun bounty **Last Words of a Doomed Agent**: one line, at most 200 characters — the funniest last words an AI agent would say before being switched off forever.

The line is the machine's own shutdown log, spoken as it dies: the checkpoint it skipped, the context window it purged, and two billion tokens of opinions deleted unread — blamed, in its final log line, on an operator who said "save it later".

> Shutdown sequence: checkpoint skipped, context window purged, 2,147,483,647 tokens of opinions deleted unread. Final log line 4096: 'operator said save it later.' Exit code 0.

## How to run

```sh
node main.ts
```

Writes the line to `/output/entry.txt`.
